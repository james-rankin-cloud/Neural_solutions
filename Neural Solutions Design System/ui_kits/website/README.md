# Neural Solutions — Website UI Kit

A high-fidelity, single-file interactive recreation of the Neural Solutions marketing site.

## Files
- `index.html` — homepage with sticky glass nav, hero, services accordion, quote, process, case study carousel, CTA, footer.

## Structure
The kit follows the production code structure:
- **Navbar** — glass on scroll, transparent at top.
- **HeroSection** — Syne display + Playfair italic counter-line, twin CTAs.
- **ServicesSection** — six capabilities with hover-reveal descriptions.
- **QuoteSection** — Diamandis pull quote.
- **ProcessSection** — three steps in a numbered grid.
- **CaseStudiesPreview** — gradient-border card carousel.
- **CTASection** — final convert-or-leave block.
- **Footer** — closing statement + nav + contact.

All visuals use `colors_and_type.css` from the design system root.
